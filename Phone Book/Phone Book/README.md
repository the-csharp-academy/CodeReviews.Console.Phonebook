# Phone Book

This is a Phone Book where you can manage your contacts.

## Features

* Viewing contacts
* Adding contacts
* Deleting contact
* Updating contact

## Built with

* C#
* .NET
* Entity Framework Core
* SQL Server
* Spectre Console

## How to use

* Choose menu option using ⬆️⬇️ and Enter
* Follow the instructions 
* Done 👍



## What i learned
* In this project, I learned Entity Framework Core and how it connects to SQL Server. I also learned about Code First and what it is.
